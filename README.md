Token Radar builds a radar-2 scored board of 200 pre-token protocols, covering all 40/40 watchlist entries. It includes 160 early rows below the $50M TVL floor and sets aside 24 live-token protocols with market caps. Implied value is round(TVL x 0.30 x growth multiplier x sqrt-maturity multiplier x chain-breadth multiplier). Every row includes a six-step costed farm plan, and the static offline dashboard has hash-routed protocol detail pages.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input /input/snapshot.json
```
